# Vision Cart - Getting Started Checklist

Use this checklist to track your setup and launch!

## 📋 Pre-Setup

- [ ] Node.js installed (v16+)
- [ ] Python 3.8+ installed
- [ ] Git installed
- [ ] Code editor ready (VS Code recommended)
- [ ] Terminal/command line open

## 🔑 API Keys Setup

- [ ] Created Clarifai account
- [ ] Generated Clarifai PAT key
- [ ] Saved Clarifai PAT somewhere safe
- [ ] Created SerpApi account
- [ ] Copied SerpApi API key
- [ ] Saved SerpApi key somewhere safe

## 🛠️ Installation

- [ ] Downloaded/cloned Vision Cart project
- [ ] Navigated to project directory
- [ ] Ran `./setup.sh` OR completed manual setup
- [ ] Backend dependencies installed
- [ ] Frontend dependencies installed
- [ ] Created `.env` file in backend/
- [ ] Added CLARIFAI_PAT to `.env`
- [ ] Added SERPAPI_KEY to `.env`

## 🧪 Testing

### Backend Testing
- [ ] Started backend: `cd backend && python3 app.py`
- [ ] Backend running on port 5000
- [ ] Tested health endpoint: `curl http://localhost:5000/api/health`
- [ ] Health check returned success

### Frontend Testing
- [ ] Started frontend: `cd frontend && npm start`
- [ ] Frontend opened in browser (port 3000)
- [ ] Upload area displays correctly
- [ ] Page is responsive on mobile size

## ✅ First Product Test

- [ ] Found a test image (clothing/shoes/accessories)
- [ ] Uploaded image via drag-and-drop
- [ ] OR uploaded image via click-to-select
- [ ] Loading indicator appeared
- [ ] Product(s) identified successfully
- [ ] Confidence score displayed
- [ ] Shopping links appeared
- [ ] Clicked a shopping link
- [ ] Link opened correctly in new tab
